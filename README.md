# Personal Resume & Portfolio Website

## Project Overview

This project is a personal resume and portfolio website developed as part of my Web Development assignment.

Instead of presenting my resume only as a traditional list of qualifications, I designed the website as a personal journey. It presents my academic background, experiences, skills, projects and interests through a combination of storytelling, visual sections and responsive web design.

The website is designed to be simple, professional and personal while demonstrating my understanding of HTML, CSS and responsive web development.

---

## Objective

The main objectives of this project are:

- To create a personal resume website using HTML and CSS.
- To present my academic and personal journey in an engaging format.
- To demonstrate practical knowledge of CSS styling and responsive design.
- To organize my skills, experiences and projects in a structured way.
- To create a website that can be viewed on desktop, tablet and mobile devices.
- To publish the website online using GitHub Pages.

---

## Technologies Used

### HTML5

HTML5 is used to create the structure and content of the website, including the navigation bar, sections, headings, paragraphs, images, timeline, projects and footer.

### CSS3

Custom CSS is used for the main visual design of the website, including:

- Colour palette
- Typography
- Spacing
- Layout
- Timeline
- Cards
- Buttons
- Images
- Hover effects
- Responsive design

### Bootstrap 5

Bootstrap 5 is included to support responsive layout and basic structure. However, the main visual appearance of the website is created using my own custom CSS.

### Google Fonts

The website uses:

- Playfair Display
- DM Sans

These fonts create a visual difference between headings and body text while maintaining readability.

### GitHub

GitHub is used to store and manage the source code of the project.

### GitHub Pages

GitHub Pages is used to host the website online.

## 1. Hero Section

The Hero section introduces me with the heading:

**"Hello. Namaskar. Meet me."**

It contains my name, a short introduction, profile image and navigation links.

### Design Decision

I wanted the first section to feel personal instead of looking like a traditional resume header. The greeting and profile image help create a direct introduction for the visitor.

---

## 2. About Section

The About section provides a short introduction about my background, interests and approach toward learning and technology.

The section focuses on my development not only as a student but also through experiences that helped me develop communication, teamwork and problem-solving skills.

---

## 3. Journey / Timeline

The Journey section presents important stages of my development through a visual timeline.

The timeline includes:

- School
- Class 12
- COVID-19 experience
- College
- Development of technical interests

Instead of presenting my education as a simple list, I used a timeline to show how different experiences influenced my development over time.

# Design Decisions

## Colour Palette

The website uses a warm and soft colour palette instead of a traditional blue or black-heavy portfolio design.

| Colour | Hex Code | Usage |
|---|---|---|
| Peach | #FDEBDD | Main background |
| Apricot |`#FDBE8A | Visual blocks |
| Coral | #EA8F84 | Accents and buttons |
| Light Coral | #F3B0A6 | Supporting elements |
| Cream | #F7E9DF | Cards and sections |
| Dark Charcoal | #3F3937 | Main text |
| Warm Grey | #756D69 | Secondary text |

The warm colours were selected to create a friendly and personal appearance while keeping the website professional.

# Typography

The website uses two fonts:

### Playfair Display

Used mainly for large headings and important titles.

### DM Sans

Used for body text, navigation and smaller interface elements.

The combination provides a contrast between the editorial-style headings and clean readable body text.

# Layout and Visual Hierarchy

The website uses different layouts for different types of information.

Large headings introduce major sections, while smaller headings organize the content within each section.

Cards are used for projects and skills to divide information into smaller and readable blocks.

Whitespace is intentionally used between sections to prevent the website from feeling crowded.

# Responsive Design

The website is designed to work on:

- Desktop
- Laptop
- Tablet
- Mobile

CSS media queries are used to adjust layouts, spacing, images, cards and text sizes on smaller screens.


# Bootstrap and Custom CSS

Bootstrap 5 is used for basic responsive structure and layout support.

However, the visual design of the website is mainly created using custom CSS.

Custom CSS is used for:

- Colours
- Typography
- Navigation
- Hero section
- Timeline
- Cards
- Buttons
- Images
- Footer
- Responsive adjustments

This allowed me to use Bootstrap while still demonstrating my own CSS styling skills.
